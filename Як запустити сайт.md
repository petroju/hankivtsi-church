# Як запустити сайт і адмін-частину

Сайт лежить на **GitHub** (там зберігаються всі файли), а показує його людям **Netlify** (безкоштовно). Адмін-частина — сторінка `/admin`, вхід через GitHub.

## 1. GitHub
1. Зареєструйтеся на github.com (якщо ще немає акаунта).
2. Створіть новий репозиторій, наприклад `hankivtsi-church`. Без README, порожній.
3. Напишіть Claude назву акаунта і репозиторію (наприклад `vlad/hankivtsi-church`). Claude впише її в `site/admin/config.yml` і підготує файли.
4. Найпростіше завантажити папку через **GitHub Desktop**: File → Add local repository → вибрати папку `Church website` → Publish repository.

## 2. Netlify (показує сайт людям)
1. Зайдіть на netlify.com → Sign up → **через GitHub**.
2. Add new site → Import an existing project → GitHub → виберіть `hankivtsi-church`.
3. Налаштування підтягнуться самі (файл `netlify.toml` каже публікувати папку `site`). Натисніть Deploy.
4. Сайт отримає адресу на зразок `hankivtsi-church.netlify.app`. Пізніше можна підключити своє ім’я, наприклад `hankivtsi-church.org.ua`.

## 3. Вхід в адмінку через GitHub
1. GitHub → Settings → Developer settings → OAuth Apps → **New OAuth App**:
   - Homepage URL: адреса сайту з Netlify
   - Authorization callback URL: `https://api.netlify.com/auth/done`
2. Скопіюйте Client ID і створіть Client Secret.
3. Netlify → ваш сайт → Site configuration → Access & security → OAuth → **Install provider** → GitHub → вставте Client ID і Secret.
4. Відкрийте `адреса-сайту/admin` → **Sign In with GitHub**.

## 4. Доступ фотографа
GitHub → репозиторій → Settings → Collaborators → **Add people** → акаунт фотографа. Після цього фотограф заходить на `/admin` так само.

## Що є в адмінці
- **Розклад**: постійний розклад і «Служби на цей тиждень» (дата, час, назва). Минулі служби зникають із сайту самі.
- **Фотоальбоми**: назва, дата, подія (Недільна Літургія, Великдень, Храмове свято…), фото з підписами. На сторінці «Фото» альбоми групуються за роками.
- **Контакти**: вулиця, пошта, телефон — з’являються внизу головної.

Кожне збереження в адмінці — це зміна у GitHub; Netlify за хвилину оновлює сайт.

## Фото, які чекають
- `site/img/bishops/epifaniy.jpg`, `site/img/bishops/ioasaf.jpg` — фото владик біля їхніх слів.
- `site/img/life/sunday-1.jpg`, `site/img/life/sunday-2.jpg` — два недільні фото на головній.
Поки файлів немає, сайт показує акуратні місця «Фото скоро з’явиться».
